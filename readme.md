# ระบบบทเรียนคอมพิวเตอร์ช่วยสอน (CAI): วิทยาการคำนวณ (AR)

คอร์สแวร์รายวิชาวิทยาการคำนวณ (21034564) สำหรับนักศึกษาครูชั้นปีที่ 3 สาขานวัตกรรมและคอมพิวเตอร์ศึกษา คณะครุศาสตร์ มหาวิทยาลัยราชภัฏสกลนคร 

โปรเจกต์นี้พัฒนาในรูปแบบ Single-Page Application (SPA) ผ่านไฟล์ HTML ไฟล์เดียว ร่วมกับการใช้ **Supabase** เป็นระบบจัดการฐานข้อมูล (Backend-as-a-Service) สำหรับเก็บข้อมูลผู้ใช้ ความก้าวหน้า คะแนนสอบ และไฟล์สื่อการสอน

## 🌟 ฟีเจอร์หลัก

### 👨‍🎓 สำหรับผู้เรียน
*   **ระบบเข้าสู่ระบบที่ปลอดภัย:** สมัครและเข้าใช้งานด้วยอีเมลรูปแบบ `<รหัสนักศึกษา>@cai.snru.ac.th` (ตรวจสอบรายชื่อจากฐานข้อมูล)
*   **บทเรียนแบบโต้ตอบ (Interactive):** เนื้อหา 5 หน่วยการเรียนรู้ พร้อมคำถามทบทวนระหว่างเรียนที่ต้องตอบถูกจึงจะผ่านได้
*   **ระบบทดสอบคู่ขนาน:** แบบทดสอบก่อนเรียนและหลังเรียนชุด A และ B (สลับชุดอัตโนมัติตามเลขท้ายรหัสนักศึกษา)
*   **ปฏิบัติการ WebAR:** รองรับการแสดงผล 3D Model (`.glb`) ผ่าน `<model-viewer>` และฟอร์มส่งงาน (อัปโหลดไฟล์หรือแนบลิงก์)
*   **โปรไฟล์ส่วนตัว:** ดูสรุปความก้าวหน้า คะแนนสอบ และอัปโหลดรูปโปรไฟล์ (ระบบบีบอัดรูปก่อนอัปโหลด)

### 👩‍🏫 สำหรับผู้สอน
*   **แดชบอร์ดสรุปผล:** ดูสรุปคะแนนสอบก่อนเรียน หลังเรียน และค่าพัฒนาการ (Normalized Gain) ของนักศึกษาทุกคน
*   **ระบบตรวจงาน:** เปิดดูลิงก์หรือไฟล์งานปฏิบัติการ ให้คะแนน และพิมพ์ข้อเสนอแนะกลับไปยังผู้เรียนได้
*   **จัดการสื่อการสอน:** อัปโหลดไฟล์เอกสาร (PDF, PPTX, DOCX) หรือเพิ่มลิงก์วิดีโอ เพื่อให้นักศึกษาศึกษาเพิ่มเติม
*   **ส่งออกข้อมูล:** ดาวน์โหลดผลคะแนนทั้งหมดเป็นไฟล์ CSV (เข้ารหัส UTF-8 with BOM เพื่อให้อ่านภาษาไทยบน Excel ได้สมบูรณ์)

2.  `setup.sql`: สคริปต์สำหรับสร้างตาราง, Policies, Triggers, Storage Buckets และข้อมูลจำลอง

## 🚀 คู่มือการติดตั้งและตั้งค่า (Deployment Guide)

### ส่วนที่ 1: การเตรียมฐานข้อมูล (Supabase)
1. สมัครใช้งานและสร้างโปรเจกต์ใหม่ที่ [Supabase](https://supabase.com) (จดจำรหัสผ่าน Database ไว้ให้ดี)
2. ไปที่เมนู **Authentication > Providers** -> เลือก **Email**
3. **ปิด (Toggle off)** ตัวเลือก `"Confirm email"` (เพื่อให้ผู้เรียนเข้าสู่ระบบได้ทันทีโดยไม่ต้องยืนยันอีเมล) แล้วกด Save
4. ไปที่เมนู **SQL Editor** -> กด **New query**
5. คัดลอกโค้ดทั้งหมดจากไฟล์ `setup.sql` ไปวางในช่องว่าง แล้วกดปุ่ม **RUN**
6. *(ทางเลือก)* หากต้องการเพิ่มนักศึกษาจริง ให้ไปที่เมนู **Table Editor** -> เลือกตาราง `students` -> **Insert** -> **Import data from CSV** (ไฟล์ CSV ต้องมีคอลัมน์ `id`, `title`, `first_name`, `last_name`, `section`)

### ส่วนที่ 2: การสร้างบัญชีผู้สอน
1. กลับไปที่ **SQL Editor**
2. เลื่อนไปที่ 2 บรรทัดสุดท้ายของโค้ด ที่เขียนว่า `คำสั่งตั้งผู้สอน`
3. ลบเครื่องหมายคอมเมนต์ (`--`) ออกจาก 2 บรรทัดนั้น
4. เปลี่ยนอีเมล `teacher@snru.ac.th` เป็นอีเมลจริงของผู้สอน
5. ลากคลุม (Highlight) เฉพาะ 2 บรรทัดนี้ แล้วกด **RUN** (หรือรันทีละคำสั่ง)

### ส่วนที่ 3: การเชื่อมต่อแอปพลิเคชัน
1. ไปที่เมนู **Project Settings** (ไอคอนรูปฟันเฟือง) -> **API**
2. คัดลอกค่า **Project URL** และ **Project API Keys (anon / public)**
3. เปิดไฟล์ `courseware.html` ด้วยเว็บเบราว์เซอร์
4. ในหน้าต่างตั้งค่าระบบครั้งแรก ให้นำ URL และ Key ที่คัดลอกมากรอกลงไป แล้วกด **บันทึกการตั้งค่า** (ระบบจะเก็บค่านี้ไว้ใน LocalStorage ของเบราว์เซอร์)
5. รีเฟรชหน้าเว็บ ระบบจะเข้าสู่หน้าต่าง Login พร้อมใช้งาน

## 🔒 ข้อมูลด้านความปลอดภัย (Security Notes)
*   **Row Level Security (RLS):** ฐานข้อมูลถูกล็อกด้วย RLS ผู้เรียนไม่สามารถใช้ API หรือเครื่องมือภายนอกเพื่อดูคะแนนหรือผลงานของเพื่อนได้
*   **Score Protection Trigger:** ระบบมี Trigger ที่ระดับ Database ป้องกันไม่ให้ผู้เรียนส่ง Request มาแก้ไขฟิลด์ `score` หรือ `teacher_comment` ในตารางส่งงานของตนเอง
*   **Storage Access:** ไฟล์งานและรูปโปรไฟล์ถูกเก็บในโฟลเดอร์ที่ชื่อเป็น `User ID` ของนักศึกษาแต่ละคน ผู้อื่นไม่สามารถเปิดดูได้เว้นแต่เป็นบัญชีผู้สอน
*   **No Hardcoded Secrets:** ไม่มี Service Role Key หรือข้อมูลนักศึกษาถูกฝังอยู่ในซอร์สโค้ด
